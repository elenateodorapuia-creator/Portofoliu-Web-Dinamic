# Dynamic Portfolio | GitHub API Integration

This is a dynamic, responsive Single Page Application (SPA) portfolio developed for a University Semester Project. The application seamlessly integrates with the official GitHub API to fetch and display personal repositories in an organized, visually appealing manner.

## ✨ Key Features
* **GitHub API Integration:** Asynchronously fetches public repositories using JavaScript `fetch` and async/await.
* **Client-Side Filtering:** Real-time search functionality by project name or programming language.
* **Smart Pagination:** Features a "Load More" button to maintain a clean UI, initially displaying 6 projects.
* **Error Handling & Fallback:** Includes a robust fallback mechanism that loads hardcoded JSON data if the GitHub API fails or the rate limit is exceeded.
* **Responsive UI:** Fully responsive design built with CSS Grid and Flexbox, optimized for desktop, tablet, and mobile viewing.

## 🛠️ Technologies Used
* **HTML5:** Semantic structure.
* **CSS3:** Custom variables, CSS Grid, Flexbox, hover animations.
* **Vanilla JavaScript:** ES6+ syntax, DOM manipulation, array filtering/sorting.
